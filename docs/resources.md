# RHCSA Resources

A short list of free resources. All links checked.

## The Exam
- [EX200 exam objectives](https://redhat.com/en/services/training/ex200-red-hat-certified-system-administrator-rhcsa-exam): the official list of what's tested
- [About Red Hat exams](https://www.redhat.com/en/services/certification/individual-exams): how the exam works and what to expect
- [7 tips for passing a Red Hat exam](https://www.redhat.com/en/blog/7-tips-passing-red-hat-certification-exam): from Red Hat

## Documentation
- [RHEL 10 documentation](https://docs.redhat.com/en/documentation/red_hat_enterprise_linux/10/)
- [RHEL 9 documentation](https://docs.redhat.com/en/documentation/red_hat_enterprise_linux/9)

## Learn the Command Line
- [The Linux Command Line](https://www.linuxcommand.org/tlcl.php): free book by William Shotts, a good place to start
- [tldr pages](https://tldr.sh/): short, practical examples for common commands

## Get a Lab OS
- [RHEL](https://developers.redhat.com/products/rhel): free with a Red Hat Developer account
- [Rocky Linux](https://rockylinux.org/download)
- [AlmaLinux](https://almalinux.org/get-almalinux)

## Built Into Every System
You can use these during the exam, so practise with them:
- `man <command>`: the manual for a command
- `man -k <keyword>`: search all manuals for a keyword
- `<command> --help`: a quick summary of options
- `/usr/share/doc/`: extra docs and example configs installed with packages
- `vimtutor`: a 30-minute interactive vi tutorial
